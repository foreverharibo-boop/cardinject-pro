# CardInject Pro

캐릭터 시트에서 만든 카테고리를 생성 프롬프트에 추가하는 SillyTavern 확장입니다.

## 1.2.3 이름 변경

표시 이름을 **CardInject Pro**로 변경했습니다. 주입 로직과 기존 설정 키·연동 API는 유지합니다. 설치 폴더는 기존 폴더에 그대로 덮어쓰세요.

## 1.2.2 수정 사항

- 기존 프리셋 항목·마커를 재배치하던 기능과 UI를 제거했습니다. 저장된 `presetPositions`, `markerOriginalOrders`는 실행하지 않습니다.
- 기존 프롬프트의 본문·활성 여부·저장 순서와 작가노트 원문을 수정하지 않습니다. 프리셋 상대 위치 옵션은 **자기 카테고리를 추가할 기준**만 선택합니다.
- 생성 인터셉터에서 채팅 배열에 가짜 메시지를 넣던 코드를 제거했습니다. 분석 후 채팅 배열과 메시지 DOM을 삭제하던 코드도 제거했습니다.
- 최신 카드인젝트와 동일한 `injection-runtime.js`, `hook-chain.js`를 사용합니다. 표준 `setExtensionPrompt` 등록과 본답변 전송 직전 재확인을 함께 사용합니다.
- 요청 발신 경로와 실제 최신 채팅 턴을 확인한 Chat Completion 본답변만 보충합니다. 번역기에 의해 본답변이 `quiet`로 요청돼도 확인된 본생성 경로라면 처리합니다. raw/custom-request 보조 생성, 확인되지 않은 요청은 변경하지 않습니다.
- 전송용 메시지 사본에만 자기 카테고리를 추가합니다. 전달된 모델·생성 유형·샘플링 값·스트리밍 설정·헤더·취소 신호는 유지합니다.
- 기존 최상단·채팅 앞·depth 15/5/2·사용자 지정 depth·작가노트·최하단·프리셋 항목 앞뒤 위치를 유지합니다. `pre_assist`는 저장값을 유지하면서 **assistant 프리필에서 system 역할 depth 0 주입으로 변경**했습니다.
- 프리셋 기준 항목이 꺼져 있거나 본문 경계를 확실히 찾지 못하면 최하단(depth 0)으로 보충하고 `[CSI] 주입 위치 대체` 로그로 알립니다. 작가노트를 찾지 못하면 설정된 작가노트 depth를 사용합니다.
- 다른 확장의 등록 프롬프트 ID는 삭제하지 않습니다. 비활성화 시 자기 ID와 이벤트만 정리하며, 공유 fetch 체인을 옛 함수로 되돌리지 않습니다.
- 자동 분석은 별도 분석용 연결 프로필에 백그라운드 요청을 보냅니다. 본채팅 연결 프로필은 변경하지 않습니다. 분석 서비스가 없으면 오류를 표시하고 본채팅 생성으로 우회하지 않습니다.
- 기존 `charsheet_injector` 카테고리 저장 구조와 `CharSheetInjectorBridge.addKink`를 유지했습니다. 분석 중 캐릭터를 바꿔도 결과는 분석을 시작한 캐릭터에 저장됩니다.

## 설치

ZIP 안 `CharSheet-Injector-main` 폴더의 파일을 **현재 설치된 캐시트 인젝터 폴더 안에** 덮어쓴 뒤 SillyTavern 페이지를 새로고침하세요. `index.js`뿐 아니라 새 `injection-runtime.js`, `hook-chain.js`, `manifest.json`도 필요합니다. 기존 설치 폴더의 `.git`은 유지하세요. 이전 버전을 별도 확장으로 동시에 실행하지 마세요.

이미 구버전이 바꾼 프리셋은 이 업데이트가 자동으로 되돌리지 않습니다. 현재 프리셋을 다시 건드리지 않도록 복원 코드를 제거했으므로, 기존 손상은 사용자가 보관한 정상 프리셋으로 복구해야 합니다.

자동 분석을 쓸 때는 확장 설정에서 **캐시트 분석용 연결 프로필**을 선택하세요. 수동으로 저장된 카테고리 주입에는 분석용 프로필이 필요하지 않습니다.

## 검수 범위

1.2.2 주입 수정에서 소스 검수와 배포 ZIP 재압축 해제 검수를 각각 수행했습니다. 각 검수에서 22개 자동 검사가 통과했습니다. 그중 동시 사용 검사는 캐시트 인젝터·카드인젝트·또또의 6가지 로드 순서마다 200회 생성 요청을 실행해 프리셋·채팅 보존, 중복 방지, 훅 누적 방지, 비활성화, 후속 확장 래퍼를 확인했습니다.

1.2.3은 이름 문자열 외의 주입 코드가 동일함을 확인하고, 소스와 압축 해제본에서 각각 자체 검사 15개를 재실행했습니다.

코드와 모의 ST 요청 검수이며, 사용자 환경에서 실제 모델 응답까지 실행한 검증은 아닙니다. 전송 직전 보충 경로의 검수 대상은 `/api/backends/chat-completions/generate`입니다. Text Completion의 최종 전송 보충은 검수 대상에 포함하지 않습니다.

자체 테스트: `npm test` 또는 `node --test tests/*.test.mjs`.
